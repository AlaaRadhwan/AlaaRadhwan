# Alaa Shamsan

**Robotics Software · Autonomy · Control**

I'm a Mechatronics Engineering student at Sakarya University of Applied Sciences in Türkiye. My work focuses on robot navigation, control, simulation, and embedded systems.

I enjoy the engineering work behind getting a robot to behave reliably: integrating components, investigating unexpected behavior, and testing changes against measurable results.

## Selected projects

- [**Autonomous Warehouse AMR**](https://github.com/AlaaRadhwan/warehouse_amr) — Built a ROS 2 / Nav2 simulation with station missions, lane-based routing, localization, and MPPI control. Investigated a 7.8% yaw-rate mismatch through system identification and reduced unnecessary reversing in a routed test.

- [**Spot Quadruped — ROS 2 & Navigation**](https://github.com/AlaaRadhwan/spot_ros2_ws) — Deployed a learned locomotion policy in Gazebo through `ros2_control`, then integrated LiDAR SLAM, AMCL, and Nav2 for autonomous navigation.

- [**Spot Quadruped — Locomotion Training**](https://github.com/AlaaRadhwan/spot_locomotion_v2) — Developed and evaluated a MuJoCo model, characterized actuator behavior, and trained a PPO velocity-tracking policy.

- [**Tiltable Quadrotor — End-Effector NMPC**](https://github.com/AlaaRadhwan/tiltable-quadrotor-nmpc) — Developed a simulated 17-state nonlinear MPC system for a tilt-rotor quadrotor, achieving 19.8 mm RMS end-effector position error in a 6-DoF tracking test.

- [**Underwater Rocket — ESP32 Firmware**](https://github.com/AlaaRadhwan/underwater-rocket-esp32-firmware) — Developed embedded C++ firmware for IMU acquisition, attitude estimation, feedback control, four-fin actuation, and operator control; participated in qualitative pool testing.

I also worked on communication and mission software for a dual-ROV system as part of a team that placed **second at TEKNOFEST 2026 Underwater Systems**.
